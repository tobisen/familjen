Starta Familjen igen

Återställ bara Familjens service worker och statiska cache. Din registrerade session och serverlagrade aktiviteter raderas inte.

Chrome säger redan installerad, men appen saknas

Cacheknappen ovan återställer webbappen. Den kan inte avregistrera en Android-app eller en felaktig WebAPK-post i Chrome.

I Chrome 155.0.8059.41 kan andra appar på samma domän göra att Familjen felaktigt visas som installerad. Rensa inte data och avinstallera inte andra appar för detta. Öppna Familjens Inställningar → Hjälp med installation och start och prova Installera Familjen om knappen visas. Den använder Chromes direkta installationshändelse; ingen fungerande Pixel-installation utlovas.

  1. Uppdatera Chrome i Play Butik. Android → Inställningar → Appar → Chrome → Tvinga avslut. Öppna Chrome igen. Välj inte Rensa lagring.
  2. Skriv chrome://webapks i Chromes adressfält. Leta efter Familjen och kontrollera att Scope och Manifest Start URL är https://tobisen.github.io/familjen/. Kontrollera även om en annan app har scope över hela tobisen.github.io.
  3. Om Familjen finns: anteckna Package name och Owning Browser. Avinstallera bara det identifierade paketet om Android hittar det. Update-knappen kan begära en uppdatering, men är ingen avinstallationsknapp och kan kräva att appen går att starta.
  4. Om posten saknas eller appen fortfarande inte går att öppna: starta om telefonen och testa installation från webbplatsens startsida igen. Den fungerande vanliga genvägen kan användas tills Chrome-felet är löst.

Om felet kvarstår behövs Chrome-version, Android-version och uppgifterna från chrome://webapks. Webbappen kan inte reparera Chromes paketregister. Rensa inte all Chrome-data. En eventuell återställning av webbplatsdata för tobisen.github.io kan logga ut även andra appar på samma domän och kräva en ny personlig kod.

Kontrollen läser webbappens offentliga konfiguration. Den läser inte din session och ändrar ingen lagring.
